# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, criticise ideas and results rather than people, and keep discussions on topic. Harassment, personal attacks and discriminatory language are not accepted.

Report unacceptable behaviour to the maintainer through GitHub (open a private security advisory if it must stay private). Reports are handled confidentially; the maintainer may remove content or block participants who break this code.
